# Project Documentation

## Project Overview

This project is a client-side storage mini hackathon project.  
We created a webpage that uses **localStorage** to personalize the user experience by saving:
- The user’s name and greeting  
- The selected theme (light, dark, red)  
- User-created notes that stay saved even after refreshing  

The purpose is to demonstrate how to **set**, **get**, and **remove** data from client-side storage and show persistence across sessions.
